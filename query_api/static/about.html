About the project

A production-style, real-time fraud detection system built end to end — from streaming ingestion to an ML scorer to a live dashboard, deployed on Kubernetes with GitOps.

The problem

Credit-card fraud is rare and highly imbalanced — under 0.2% of transactions in the public Kaggle Credit Card Fraud dataset are fraudulent. Rather than train on scarce labels, this system uses an unsupervised anomaly detector (Isolation Forest) that learns what "normal" spending looks like and flags outliers in real time.

How it works

End-to-end flow
Producer→ Kafka→ Scoring (ML)→ Query API→ Postgres + SSE Dashboard

A producer replays held-out transactions into a Kafka topic. The scoring service consumes them, runs the model, and publishes risk scores to a second topic. The query API (FastAPI) persists results to Postgres and pushes aggregated metrics to the dashboard over Server-Sent Events every 200 ms — live rate, latency p95, risk distribution and fraud flags.

The model

AlgorithmIsolation Forest (scikit-learn), unsupervised anomaly detection
PreprocessingRobustScaler on Time/Amount, fit on normal-only rows to avoid label leakage
ThresholdTuned for F2 (recall-weighted) with a minimum-precision floor
ServingReplays only the held-out test split, so the model scores unseen transactions
